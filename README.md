# Alice Free PWA 1.0

Полностью бесплатная статическая PWA для GitHub Pages. Не требует OpenAI API, Vercel, карты или платной подписки.

## Возможности
- 4 образа Алисы;
- атмосферы: камин / снег / комната / ночь;
- настроение: нежная / игривая / спокойная / мечтательная;
- голос iPhone через Speech Synthesis;
- попытка русской голосовой расшифровки через Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`), если браузер её поддерживает;
- текстовый режим как гарантированный бесплатный fallback;
- локальные сценарные ответы и персональные настройки в `localStorage`;
- установка на экран Домой.

## Ограничение
Без внешней ИИ-модели это не полноценный ChatGPT: ответы строятся локально по набору правил и шаблонов. На iPhone поддержка распознавания голоса в Safari/PWA может зависеть от версии iOS, поэтому текстовый ввод оставлен обязательным fallback.

## GitHub Pages
Загрузи содержимое папки в корень публичного репозитория. Затем Settings → Pages → Deploy from a branch → main → /(root) → Save.
